# 🚶 Real User Journey Scenarios

## Journey 1: Morning Devotional Swadhyay (Sadhana $\rightarrow$ Darshan)
1. User wakes up at 06:00 IST (Prabhat/Mangala watch).
2. Opens `https://bhav.vrindopnishad.in`.
3. Views active Mangala Aarti schedule and Bankey Bihari Darshan card.
4. Performs 1 mala of Japa using the tactile ring counter.
5. Saves daily resolve ("श्रीजी के चरणों में अनन्य प्रीति").
6. Result: Streak counter increments, state is saved to IndexedDB.

## Journey 2: Deep Scripture Study (Path $\rightarrow$ Valmiki Ramayana)
1. User visits `https://path.vrindopnishad.in`.
2. Taps on Valmiki Ramayana pothi card.
3. Taps the top navigation pill: selects Sundarakanda $\rightarrow$ Sarga 14.
4. Reads 10 shlokas in continuous stream mode with Braj purport.
5. Uses direct numeric jumper to navigate to Shloka 25.
6. Bookmarks Shloka 25.
7. Refreshes page: reading position is restored to Sarga 14, Shloka 25.

## Journey 3: Rasik Pada Discovery (Bhav $\rightarrow$ Padavali)
1. User visits `https://bhav.vrindopnishad.in/?tab=padavali`.
2. Searches for "भोरी सखी" in Saints directory.
3. Clicks on Shri Bhori Sakhi profile: all 62 padas load instantly.
4. Opens Pad 1, listens to audio recitation, toggles Devanagari/transliteration.
5. Opens Rasik Lexicon sheet to check meaning of "नित्य निकुंज".
