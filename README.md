# the-vrinda (वृन्दोपनिषद् २.०)

> A modern, responsive, contemplative spiritual sanctuary and rasik padavali reader built for all mobile and desktop devices.

## Features
- **Nitya Smaran & Sacred Japa**: Real-time counter, Ashtayama cycle sync, daily darshan timings.
- **Padavali Reader**: Complete Braj Bhasha canonical library with customizable typography, ambiance themes (*Ivory, Sage Mint, Chandan Gold, Twilight Night*), and inline Braj glossary.
- **Dhyana Focus Sanctuary**: 4-4-4 Pranayama breathing pacer and neural/spiritual impact metrics.
- **Rasik Feed**: Daily darshan updates, bilingual Hindi/IAST translation, bookmarking, and IDB persistence.
- **Devotional Milestones**: Achievement badges and continuous niyama streak tracking.
- **High Performance Architecture**: Sub-0.1ms synchronous L1 cache, IndexedDB persistence, and GPU-bypassed `.low-spec` mode for smooth 60fps across budget smartphones.

## Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Run production build
npm run build

# Run automated E2E & adversarial stress test gates
npm run test
```
